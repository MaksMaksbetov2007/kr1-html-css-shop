# Northline Auto — одностраничный каталог GMC и Ford

## Как открыть
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для загрузки фотографий требуется интернет — они загружаются с официальных сайтов GMC и Ford.

## Возможности
- Одна страница: первый экран, каталог, информация и форма связи.
- Четыре модели: GMC Sierra 1500, GMC Yukon, Ford F-150 и Ford Bronco.
- Поиск, фильтр по марке, сортировка, избранное.
- Адаптивная верстка для компьютера и телефона.
- Проверка обязательных полей формы.

## Важно
Это учебный демонстрационный сайт. Вместо выдуманных цен указано «Цена по запросу». Форма не отправляет данные на сервер. Фото взяты с официальных страниц производителей; URL изображений могут измениться при обновлении сайтов.

## Источники фотографий
- GMC Sierra 1500: https://www.gmc.com/trucks/sierra/1500
- GMC Yukon: https://www.gmc.com/suvs/yukon
- Ford F-150: https://www.ford.com/f-150/
- Ford Bronco: https://www.ford.ca/suvs/bronco/

## Структура
- `index.html` — вся страница.
- `css/style.css` — оформление и адаптивность.
- `js/main.js` — поиск, фильтры, избранное, меню и форма.
